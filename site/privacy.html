Updated September 29, 2026. This describes QueueScope 0.5.0 and this website.

The desktop app

QueueScope connects from your Mac to the Redis and SSH servers you configure. It does not send queue payloads or Redis credentials to a QueueScope service. Release builds save Redis credentials in macOS Keychain. Connection metadata and metric snapshots are stored locally.

When you choose Check for Updates, Sparkle contacts GitHub to check for and download releases. GitHub receives standard network request information. SSH connections use your configured server and system SSH settings. The offline demo uses sample data without connecting to Redis.

Development builds use separate, unencrypted local credential storage to avoid repeated Keychain prompts. Use the signed release for Keychain-backed storage.

This website

This site has no analytics scripts, advertising trackers, or application cookies. GitHub Pages hosts it and may process request information under GitHub’s privacy policies. Download and GitHub links take you to GitHub.

Feedback and contact

GitHub issues are public. Please do not include credentials, customer payloads, or private server details. Information you send by email is used to respond and help improve QueueScope. Contact ray@nirola.in to ask about or request deletion of feedback sent directly to us.
