A Bull Board alternative for macOS

Choose a dashboard around where you work and who needs access. QueueScope is a free, open-source Mac app for developers who want to inspect BullMQ without deploying a dashboard server.

Two different ways to reach your queues

Bull Board runs as a web dashboard inside a server application. Its adapters let you integrate a queue UI with frameworks such as Express. That is useful when you want a browser interface your team can reach. You decide how to host and protect that endpoint.

QueueScope runs locally on macOS. Add a Redis connection, discover your queues, and inspect them from the app. It can reach private Redis through your SSH keys or agent. No QueueScope account or dashboard server is required.

Choose QueueScope for a local debugging workflow

Start with a read-only connection. Use the failure inbox to group similar errors across queues, open a representative job to inspect its payload and stack trace, then follow parent and child jobs in the flow graph. Writable connections expose eligible BullMQ-backed job actions.

Release builds store Redis credentials in macOS Keychain. The app includes its Node runtime for job actions, so the downloaded app does not require a separate Node installation.

Choose a server dashboard for shared browser access

If teammates need the same URL, your developers use different operating systems, or you already have an authenticated operations application, a server dashboard may fit better. QueueScope is a local Mac tool; it does not provide a shared hosted dashboard, team accounts, or an alerting service.

Try the offline demo before configuring a connection: open Connection Manager and select Explore offline demo. You can inspect sample failures and flows without connecting to Redis.
